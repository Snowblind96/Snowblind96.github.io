# Nicholas Olsen — Academic Home Page

A single-file, self-contained academic home page.

## View
Open `index.html` in any browser.

## Deploy on GitHub Pages (free, custom URL)
1. Create a GitHub repository (e.g. `nicholas-olsen` or any name).
2. In that repo, click **Add file → Upload files** and drag in **`index.html`**.
3. Commit. Then go to **Settings → Pages → Source** and select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Your site is live at `https://<yourusername>.github.io/<repo-name>/`.
5. (Optional) For a cleaner URL at `https://<yourusername>.github.io/`, name the repo exactly `<yourusername>.github.io`.
